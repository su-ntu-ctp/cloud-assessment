# (SCTP) Advanced Professional Certificate in Cloud Infrastructure Engineering - Technical Assessment

## Getting started

You must have a GitHub account to proceed with this assessment. You may [create a free account](https://github.com/signup) if you do not already have one.

Click on the Code button and select the <khb>Codespaces</khb> tab to create a new Codespace.

## Running tests

Run tests with `pytest` to check your solutions.

```sh
pytest
```
